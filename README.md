# ai-course-lab1

Class 1 lab project for the AI Engineering course.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Project layout

- `data/raw/`        raw inputs (not committed)
- `data/processed/`  cleaned data produced by code
- `notebooks/`       exploration
- `src/`             reusable code
- `tests/`           tests
